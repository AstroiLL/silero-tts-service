# silero-tts-service — один синтез русской речи на всех

Сервис озвучивает текст голосом [Silero](https://github.com/snakers4/silero-models): бесплатно, без облака,
на обычном CPU. Его ставят **один раз**, а пользуются все: несколько пользователей одного сервера,
разные ИИ-агенты, другие машины в домашней сети.

## Зачем

Модель синтеза вместе с PyTorch занимает около 900 МБ на диске и около 800 МБ памяти. Если каждый агент
держит свою копию, это быстро становится дорого. К тому же разовый запуск каждый раз заново грузит
модель, и первая фраза ждёт около 3 секунд.

Сервис держит модель в памяти постоянно:

- фраза озвучивается за **~0,2 с**, длинный текст на 3 минуты звучания — примерно за 9 с;
- память занята один раз, сколько бы ни было клиентов;
- синтез можно вынести на самую мощную машину в сети, а остальные будут к ней обращаться.

## Что умеет

- 🔌 **API как у OpenAI** (`/v1/audio/speech`). Подходит любой клиент OpenAI TTS:
  [Hermes Agent](https://github.com/NousResearch/hermes-agent), [Чуйко](https://github.com/AstroiLL/chuyko),
  Open WebUI, n8n, свои скрипты.
- 🔑 **Свой токен у каждого клиента.** Выдаётся и отзывается одной командой, без перезапуска.
  В файле хранятся только хэши токенов.
- 🗣️ **Голоса Silero:** eugene, aidar (мужские), xenia, kseniya, baya (женские). Темп меняется без
  искажения высоты голоса.
- 📖 **Словарь ударений и чтение английских слов по-русски.** «GitHub» звучит как «гитхаб», а не
  пропускается. Свои слова можно добавлять на лету.
- 🎧 **Форматы:** opus (голосовые сообщения Telegram), mp3, wav, flac, aac, pcm.
- 📜 **Длинные тексты** режутся по предложениям и склеиваются с паузами.
- 📟 **Клиент для агентов, которые запускают TTS внешней командой:** `client/say.sh`, нужны только curl
  и python3, без PyTorch.

## Как это устроено

```
 пользователь 1: Hermes ─┐
 пользователь 2: Hermes ─┤   токен   ┌─────────────────────────┐
 Чуйко (голос с телефона)┼──────────►│  silero-tts-service     │  модель в памяти,
 другой сервер в сети ───┘   HTTP    │  :7470  /v1/audio/speech│  ~0,2 с на фразу
                                     └─────────────────────────┘
```

Пример запроса:
```sh
curl http://127.0.0.1:7470/v1/audio/speech -H "Authorization: Bearer $TOKEN" \
     -H 'Content-Type: application/json' \
     -d '{"input": "Привет! Это Silero.", "voice": "eugene", "response_format": "mp3"}' -o hello.mp3
```

## 🤖 Для агента: установка

Пошаговая инструкция с проверками лежит в **[INSTALL.md](INSTALL.md)**. Кратко:

1. Сначала проверь, нет ли сервиса уже: `curl -s http://127.0.0.1:7470/health`. Спроси пользователя,
   нет ли его на другой машине в сети. Если есть, ставить не нужно: попроси токен и подключай клиента (шаг 6).
2. Выбери режим вместе с пользователем: user-сервис (root не нужен) или системный сервис от отдельного
   пользователя (лучше для сервера, где работают несколько человек).
3. `git clone` → `./install.sh` → `tokens.py add <клиент>` → systemd-юнит из `deploy/`.
4. Подключи клиентов: Hermes, Чуйко, любой клиент OpenAI TTS. Каждому свой токен.
